# 🔐 ForensicRecovery

A lightweight digital forensic file recovery application built with **Python and Flask**.

ForensicRecovery provides a simple web-based interface for scanning common user storage locations, managing digital evidence, and safely moving files into a recovery vault where they can be restored or permanently removed.

---

## ✨ Features

- 📁 Scan common storage locations
  - Desktop
  - Downloads
  - Documents
  - Pictures
  - Videos
  - Music
  - OneDrive (when available)

- 🔍 Scan multiple sources from a single interface
- 🗑️ Move files to a Recovery Vault
- ♻️ Recover files to their original location
- ❌ Permanently delete files from the Recovery Vault
- 📍 Preserve the original file location
- 🕒 Record deletion time
- 🛡️ Basic path validation to prevent unintended locations from being accessed
- 🎨 Minimalist and responsive web interface
- 🐍 Single-file Python application
